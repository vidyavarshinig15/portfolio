# Vidyavarshini G – Portfolio

Professional portfolio presenting my projects, skills, and experience as a Computer Science Engineering undergraduate.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Style**: Tailwind CSS 4
- **Animations**: Three.js (React Three Fiber)
- **UI Components**: Radix UI (shadcn/ui)
- **Contact**: Node.js & Nodemailer SMTP messaging
- **i18n**: Multilingual support (FR/EN)
- **Deployment**: Vercel

## ✨ Key Features

- **3D Background Animations**: Clean interactive mouse particle/grid effects with Three.js.
- **Responsive Layout**: Pixel-perfect viewports for mobile, tablet, and widescreen layouts.
- **Dark/Light Mode**: Persisted theme switcher adapting to user preferences.
- **Interactive Timeline**: Responsive double-column grid layout for Education and Achievements.
- **Contact Form**: Secure form processing with dynamic console fallback logging for local development.
- **SEO Ready**: Custom XML Sitemap, search metadata, JSON-LD structured data, and robots rules.
